# World Map

## Regions
7 regions with level ranges:
- Mesto bez svitania (1-20)
- Čierny les (15-30)
- Krypty Prvých (25-40)
- Mesačné vrchy (35-50)
- Krvavé močiare (20-35)
- Pobrežie prázdnych lodí (30-45)
- Koruna zatmenia (45-50)

## Territory Types
- Fortress: defense boost
- Mine: resource yield
- Sanctuary: energy regen
- Trade Route: merchant discount
- Watchtower: enemy intel
- Relic Site: drop boost

## Control
- Territories captured via clan wars
- Max 5 per clan
- Seasonal reset
- Defense fatigue for held territories

## Dominance Protection
- Rising capture costs
- Attacker bonus vs dominant clan
- Decay on inactive territories
- Catch-up for underdog clans
